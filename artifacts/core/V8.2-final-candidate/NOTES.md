# V8.2 — единый кандидат после разбора дефектов

Исходная база — исправления Андрея `3d52812`. Включены правки V8.1 и
согласованная доработка `core/dialogue.py`, `core/engine.py`, `core/prompts.py`,
`core/retrieval.py`, `core/validation.py`. V6, прежние ZIP V8 и V8.1 сохранены.

## Что включено

- Один неизменяемый снимок намерения, клиентских выдержек и задач ответа
  создаётся внутри запроса и передаётся генерации, сборке и обработке review.
  Сведения разных пользователей не сохраняются в этом снимке между вызовами.
- Однозначные поправки расхода, в том числе без повторной единицы при том же
  периоде, заменяют прежнее значение. Разные объекты, гипотезы, вопросы и
  команды о форме резюме обрабатываются консервативно. Цель не выводится из
  мощности или расхода. Соседняя цель не теряется при выделении числового факта.
- Разбор подготовки данных больше не срабатывает только по «потребуется»
  в вопросе о SIM или по слову «расчёт» в вопросе об определении. Вопросы о
  возможностях продукта отделены от просьбы подготовить клиентские данные.
- План ответа сохраняет составные задачи, темы из user-реплик, подготовку,
  достаточность данных, резюме и фокус нагрузки/резерва. Общие источники
  остаются доступными, но соседний список другого продукта не становится
  обязательным. Тот же план получает редактор.
- Короткая ссылка на изменение конфигурации учитывает предыдущую реплику
  клиента. Для солнечного резерва поиск сохраняет подтверждение ограничения
  сетевой станции и исходное условие зарядки накопителей. Узкое расширение
  контекста не вытесняет явно выбранные другие продукты составного вопроса.
- Отдельное требование точной стоимости неизвестного продукта переводится
  в уточнение предмета. Составные вопросы не перехватываются этим правилом.
- Полезный следующий шаг связан с задачей и неизвестными параметрами.
  Инструкции отдельно сохраняют полноту конфигурации, единицы, применимость,
  существенные оговорки, границы ответственности и различие порога/разрешения.
- Защита JSON, источников, секретов, CSV, общий дедлайн и ограниченные повторы
  сохранены. Новых модельных этапов, пакетов и внешних сервисов не добавлено.
  Повторяющиеся инструкции сокращены, подсказки ограничены целыми выдержками.

## Статус

Это весь согласованный в текущем разборе пакет изменений. Исходники просмотрены
без выполнения. По прямому поручению пользователя не запускались приложение,
модель, тесты, компиляция и оценщик. Выполнена только сборка плоского ZIP штатным
упаковщиком. Старые результаты 429 тестов и 82 ответов не относятся к V8.2.

Лексические правила не разбирают любой возможный русский диалог. Для сложных
ссылок и нескольких объектов сохраняется история, неизвестное не должно
превращаться в угаданный факт. Выполнение, скорость и балл V8.2 не измерены;
отсутствие ошибок и достижение 70/100 без проверки не утверждаются.

Архив для площадки: `V8.2-energytool-complete.zip`. Внутри только 13 необходимых
корневых файлов, без данных, ключей, документации, backend и интерфейса.
