# Результат первой контрольной точки

Дата: 12 ноября 2026, МСК.

## Реализовано

Backend FastAPI, SQLite с WAL и внешними ключами, непрозрачная браузерная сессия с хэшированием токена, проверка владельца диалога, сохранение истории, архив и новый контекст при повторном открытии, идемпотентность сообщений, сериализация обращений к одному диалогу, таймаут ядра и проверка его результата.
Создан независимый от веба интерфейс Consultant и явная заглушка без продуктовых утверждений. Добавлены страница проверки, OpenAPI, API-контракт, план команды, Docker Compose, конфигурация запуска PyCharm и шаблон CI в `docs/ci/backend.yml`.

## Фактически выполненные проверки

- `python -m pytest -q`: **14 passed**. Проверены сохранение после пересоздания приложения на том же файле БД, изоляция двух сессий, отсутствие доверенных ролей с клиента, истечение cookie-сессии, хэширование токена, повтор и конфликт request_id, архив и чистая история нового диалога, история текущего чата в ядре, конкурентные сообщения, timeout, некорректный ответ, исключение ядра без раскрытия его текста, SSE, заголовки и статические файлы.
- `python -m pip check`: **No broken requirements found**.
- `node --check backend/web/app.js`: успешно.
- Реальный запуск Uvicorn, `GET /health`: HTTP 200, `status=ok`, `core_mode=stub`.
- В браузере: создан диалог, отправлено вымышленное сообщение, показан сохранённый тестовый ответ; страница перезагружена, диалог открыт из списка, оба сообщения восстановлены.
- Все семь ссылок из инструкции открыты; подробности в `SOURCES_REVIEW.md`.

Среда проверки: Windows, Python 3.12.14. Backend-зависимости и их транзитивные версии зафиксированы в `requirements-backend.txt`.
Предупреждение тестового клиента Starlette о будущем переходе с httpx на httpx2 не влияет на результаты; httpx оставлен локальной тестовой зависимостью.

## Статус окружения и ограничения

- Docker отсутствует в PATH и стандартном каталоге установки; сборка контейнера не выполнялась. Файлы запуска подготовлены, Linux CI ещё не запускался на GitHub.
- PyCharm: проект открыт, подтверждено окно `mts-energytool – README.md`. Конфигурация запуска и локальный venv подготовлены.
- GitHub CLI авторизован как ZilderMega. По уточнению владельца выбран существующий `AndLy12/AI-Consultant-Anergytool`, настроен origin. Владелец явно разрешил публикацию в PUBLIC. Новый репозиторий не создавался.
- Первый push отклонён GitHub: у авторизации нет scope workflow для загрузки `.github/workflows/backend.yml`. Шаблон перенесён в `docs/ci/backend.yml`; автоматические проверки GitHub пока не включены. Для публикации подготовлена история без workflow-файла, исходные локальные коммиты сохранены в ветке `local/checkpoint-with-workflow` и не отправляются.
- Push в `main` успешно выполнен: исходная версия backend — коммит `36488b3`. Опубликованы только файлы проекта; локальный venv, SQLite, история тестового чата и секреты не входят в Git. Репозиторий оставлен PUBLIC по прямому указанию владельца.
- Архивы базы и примера, demo CSV, оригинальный регламент и requirements платформы, доступ API и оценка платформы не проверялись: они не предоставлены для текущей точки.
