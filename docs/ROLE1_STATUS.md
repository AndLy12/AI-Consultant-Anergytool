# Статус роли 1

Роль 1: backend, хранение, API, веб-интеграция, изоляция и запуск.
Роль 2: база знаний, поиск, модель, промпты, ядро, solution.py и сабмит.
Роль 4: основной frontend; текущий HTML — проверочный каркас.
Старый PLAN_TO_MONDAY.md использует другое распределение; ориентироваться на
исходные командные инструкции и docs/DECISIONS.md.

Реализовано: аккаунты, серверные сессии, история с разных устройств, диалоги,
архив, доступ владельца, staff API, карточка/подтверждение заявки, сохранение
ошибок и отладки, контракт ядра, SQLAlchemy, Alembic, Docker/Compose и CI.

Ядро Данька из origin/core подключено без изменений: фабрика, BM25, источники,
история и demo-ответы. Открыто: реальный Qwen, frontend Даши, приёмка на настоящих
вопросах и платформенный сабмит. Docker проверяется для stub и demo отдельно.
Исходные материалы/ключи не публикуются. Backend-заглушка из командного main
заменена; core/ сохранён без изменений. Для async answer(history) добавлен
адаптер backend с постоянным event loop и проверкой результата. Статус
публикации определяется фактической историей Git, а не этим чек-листом.
