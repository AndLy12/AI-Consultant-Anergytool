## Что выяснилось по платформе

Аня предоставила историю отправок команды astonishingly, HACK&CHANGE, и
архив `core-knowledge-submission-v5.zip`. На скриншоте у v5 показаны
**8,5 балла**, «Лучшее решение», время отправки 11:10, длительность
1067,9 с (17 мин 47,9 с). У v3 показаны 7,975 и «Успешно»; ранние записи
имеют статус ошибки. Причины прежних ошибок, дата отправок и подробные
ответы на скриншоте не видны.

SHA-256 v5:
`a19fbc7136cd625d10ecc21c206d04fcb4fa6cd187515bfeb1e0370541399ff1`.
Архив исправен, содержит 13 корневых файлов; синтаксис Python проверен.
Имена файлов и зависимости соответствуют кандидату main, но **содержимое
восьми файлов отличается**: контракт, конфигурация, движок, клиент модели,
промпт, поиск, валидация и `solution.py`.

В частности, v5 допускает связный ответ модели с подтверждающими цитатами,
коррекцию невалидного ответа и дополнительный реранкер при настройке.
Поэтому результат main и поведение v5 нельзя смешивать. Фактическое
включение реранкера и параметры платформенного запуска неизвестны.
Извлечение базы модулями v5 без API также даёт 19 документов, 477 фрагментов,
233 раздела; реранкер и генерация при этом не запускались.

Оценка платформы зафиксирована в исходной шкале кабинета. 8,5 не обозначаем
как 85% наших сценариев и не пересчитываем в метрики регламента без
подтверждения шкалы. Показанная длительность не заменяет лог времени
исполнения `solution.py`: нужно понять, включает ли она другие стадии.

## Что заблокировано

Лид подтвердил через Аню: отдельного API пока нет. В облачной среде нет
адреса, ключа и модели для реального запуска. Проверка доступности создала
99 записей очереди со статусом blocked; **вызовов модели — 0, оценённых
консультаций — 0**. Это очередь с повторами, а не 99 независимых вопросов.

Ручная оценка 30 сценариев, критические повторы, восемь независимых,
настоящие диалоги, сравнение веб/CSV и повторные проверки исправлений
не выполнены. Положительный результат v5 на платформе зафиксирован,
но он не заменяет отсутствующие ответы и диагностику для этих проверок.
