# Ближайшая работа команды

| № | Ответственность | Следующая задача |
|---|---|---|
| 1 | Backend, хранение, API, интеграция и запуск | Первая точка; затем факты, согласие и недублирующаяся запись заявки |
| 2 | База, поиск, модель, промпты, история, solution.py | Проверить архивы/API, сделать BM25 baseline и адаптер Consultant |
| 3 | Проверки документов и ответов | Сценарии по реальной базе, источники, ошибки и повторная приёмка |
| 4 | Пользовательский интерфейс | Подключить чат к API v0.1; ошибки, архив, источники |
| 5 | Документы, результаты, демо и сдача | Собрать регламент и сроки, вести журнал результатов |

Первая точка: браузер → backend → сохранение user → изолированная история → stub → проверка → сохранение assistant → браузер.
Перезапуск не теряет историю; другая сессия не видит диалог. Все заявления о готовности подтверждаются проверками.
Следующая точка участника №1: согласованные поля фактов, сохранение заявки после проверки ФИО/телефона/компании/резюме/согласия; отсутствие дублей; без CRM и почты.
