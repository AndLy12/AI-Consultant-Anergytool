## Что изменилось относительно прежней задачи

Аня проверяет применимость фактов и содержание готовых ответов. Локальные
Qwen, LM Studio и API для этого не обязательны. Автоматизация и новый
независимый набор принадлежат коллеге три; генерация baseline/кандидата
и исправления production-кода — Даньку. Отсутствие API в среде Ани больше
не считается причиной откладывать всю проверку источников.

Сейчас разбор ответов ограничивает отсутствие переданного пакета генераций
и закрытых критериев коллеги три, а не необходимость установить модель.

Отметка «недостаточно данных» означает состояние проверки, а не признание,
что продуктовый дефект обязательно остаётся в новой версии. Ноль обнаруженных
ошибок при нуле разобранных ответов не считается приёмкой.
