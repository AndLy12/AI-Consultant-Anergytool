## Команды и ограничения

Python с зависимостями находится в `.venv/Scripts/python.exe` базового checkout
`mts-energytool-core`; для отдельного worktree использовать его абсолютный путь.
Основная проверка: `python -X utf8 -m pytest -q` из корня нужной версии.
Подготовка базы: отдельно `python -X utf8 -m pytest tests -q` из `knowledge-base-work`.
Модель сессии — LM Studio `energytool-eval`, huihui-qwen3.8-27b-abliterated,
локальный сервер 127.0.0.1:1234, контекст 8192, один слот, температура 0.
Ключи и адреса внешних провайдеров в отчёты не включать; `.env` не копировать.

Незавершённое не помечать пройденным. Отсутствующий счётчик — null, не ноль.
Источники старого ответа нельзя достраивать новым поиском. При остановке обновить
этот файл: последний коммит, каталоги результатов, завершённые/незавершённые шаги,
следующую точную команду и открытые дефекты. Коммит и push делать до исчерпания
доступной сессии, а не рассчитывать на её автоматическое продолжение.
