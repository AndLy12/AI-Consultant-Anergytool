## Что передать ребятам

Передать весь каталог `docs/team-6v`, а каждому — ссылку на его задачу из таблицы.
Для разработки нужны репозиторий с указанным коммитом, разрешённая база организаторов
и настройки доступной модели через окружение. Ключи передавать отдельно защищённым
способом; не включать их в MD, ZIP, Git или отчёты.

Коммит ядра создан локально. Этот пакет сам по себе не публикует изменения в GitHub
и не отправляет решение на сайт. Закрытые материалы роли 3 также не включены в Git.
