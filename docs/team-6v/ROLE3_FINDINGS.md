При неизменённой 6v четыре проверки отмечены `xfail(strict=True)` с ID дефекта.
Для проверки условий без этого маркера:

```bash
python -m pytest tests/core/test_role3_intent_quality.py --runxfail -q
```

Baseline при этой команде должен показать нарушения. Когда кандидат исправлен,
QA снимает ожидаемое падение после повторного воспроизведения; strict XPASS
в обычном прогоне не позволит незаметно сохранить устаревшую отметку.

Команды freeze/search/export-development создают новые пути и не перезаписывают
существующие артефакты. Источники не извлекаются из ZIP на диск. Полный SHA
manifest следует сверять с этой внешней фиксацией, а не только с редактируемым
паспортом рядом с данными. Измерение хранит реальный checkout SHA и хеш runtime-кода.
Wilson-интервал в инструменте — только статистическая заготовка; к отсутствующим
реальным смысловым оценкам он не применялся.
