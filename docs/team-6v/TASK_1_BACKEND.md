# №1 — владелец проекта: backend, хранение и API

В текущем цикле Данёк улучшает ядро, коллега три проверяет его, Аня проверяет факты.
Переделывать backend для этих изменений заранее не требуется.

Твоя зона и правила совместной работы: [FILE_OWNERSHIP.md](FILE_OWNERSHIP.md).
Продолжай существующую ветку `backend/role1-integration`; не сбрасывай свои коммиты
ради исходной точки ядра. Контракт — [CORE_INTEGRATION.md](../CORE_INTEGRATION.md).

Если доработка ядра выявит проблему интеграции:

1. Проверить вход CoreRequest, порядок истории, права владельца диалога и обработку
   CoreUnavailable. Историю другого пользователя и текущую реплику дважды не передавать.
2. Исправить backend в своих файлах; `core/*.py` и `solution.py` оставить Даньку.
3. Схему `core_contract.py` менять только совместно с Даньком.
4. Проверить идемпотентность, отсутствие заявки без согласия и изоляцию диалогов.
5. Передать коммит, список файлов и результаты проверок Даньку для интеграции.

Файл `TASK_1_OWNER.md` сохранён ради старых ссылок и описывает координацию Данька;
он не назначает тебе задачи по ядру. Публикацию сайта и ZIP сейчас не выполнять.
