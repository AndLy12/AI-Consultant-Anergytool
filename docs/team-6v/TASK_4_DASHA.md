# №4 — Даша: интерфейс

В текущем цикле качества ядра переделка интерфейса не требуется. Твоя зона —
`frontend/`, существующая ветка — `frontend-role4-ui`. Не сбрасывай накопленные
изменения ради ветки ядра. Правила — [FILE_OWNERSHIP.md](FILE_OWNERSHIP.md).

Если при ручной проверке обнаружена проблема отображения:

1. Проверить текст ответа, источники, предупреждения и карточку черновика.
2. Ошибку отображения исправить в `frontend/`, результат описать в своём
   `docs/team-6v/DASHA_FINDINGS.md` и передать Даньку коммит с проверками.
3. Ошибку содержания ответа передать Даньку с вопросом и фактическим ответом;
   не исправлять её заменой текста на стороне UI.
4. Если требуется изменение API, передать воспроизведение №1. Самостоятельно
   не менять backend, ядро, общий контракт, зависимости и чужие тесты.

Черновик заявки остаётся предложением: интерфейс не должен создавать заявку
без явного действия пользователя. Выкладка и сборка ZIP в этот цикл не входят.
