# V8 — журнал 30 новых исправлений

Начальная версия — `00f5895`, ветка `codex/core-v8-response-policy`.
Задание владельца проекта — исправить 30 новых подтверждённых причин ошибок без API.
Варианты одного дефекта считаются одной ошибкой. Старые исправления в счёт не входят.

Текущий подтверждённый счёт: **9/30**. Работа продолжается.

| № | Воспроизведённая причина | Исправление | Регрессия в tests/core/test_v8_regressions.py |
|---|---|---|---|
| 01 | Служебный CSV-отчёт мог перезаписать исходный файл вопросов | До записи проверяется совпадение обоих выходных путей с входом | b01 |
| 02 | Пустой CSV требовал модель и её настройки | При отсутствии строк провайдер не создаётся, формируется пустая корректная поставка | b02 |
| 03 | Ошибка записи/flush/fsync оставляла временный файл с данными | Весь цикл записи охвачен очисткой, прежний результат сохраняется | b03 |
| 04 | content_filter/tool_calls в finish_reason принимались за завершённый ответ | Завершение проверяется независимо от содержимого JSON, незавершённость — ModelResponseError | b04, две формы |
| 05 | Неверный model в HTTP 400 приводил к пяти запросам и отключению расширений для следующих диалогов | Явная ошибка основного параметра не рассматривается как отсутствие поддержки JSON | b05 |
| 06 | Слитные киловаттчасы и мегаватт-часы теряли единицу энергии при нормализации поиска | Единицы энергии распознаются до мощности, формы кВт·ч/МВт·ч согласованы | b06, три формы |
| 07 | Истёкший дедлайн подготовки не останавливал чтение базы | Проверки перед чтением, между файлами, после разбора и до построения индекса | b07 |
| 08 | Соседние Markdown-заголовки без пустых строк смешивали гарантию и обслуживание в один раздел | Заголовок на новой строке отделяет структурный фрагмент с сохранением исходных смещений | b08 |
| 09 | Ошибочный порт URL проходил валидацию провайдера | Отложенная проверка url.port выполняется до HTTP | b09 |

Все перечисленные причины воспроизведены падающими проверками до исправления.
Контроль после первой группы — 390 passed, одно прежнее предупреждение Starlette.
Настройки схемы и критерии качества не ослаблялись. Внешняя модель не вызывалась.

Ограничения: пауза дедлайна не прерывает произвольный блокирующий парсер посередине;
проверка после возврата предотвращает продолжение подготовки. Неизвестные пустые
400/422 сохраняют прежний механизм согласования возможностей старых провайдеров.
