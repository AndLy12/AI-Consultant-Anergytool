# Интерфейс участника №4

Основной frontend делает Даша. Актуальный контракт: `../docs/BACKEND.md` и `/openapi.json`.
Временная страница проверки находится в `backend/static/` и обслуживается с одного origin.
Авторизация: `/api/auth/*`, затем CSRF-токен в изменяющих запросах. Диалоги:
`/api/dialogs/*`, заявки: `/api/dialogs/{id}/application`. Старое API v0.1 заменено.
Подключайте веб-клиент через same-origin API либо dev-proxy; ключи LLM в браузер не передаются.
