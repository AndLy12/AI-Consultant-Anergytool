# Карта экранов и мини-набор стилей

Рабочий документ роли №4. Описывает, что видит пользователь и как устроено
оформление. Визуальная сложность сознательно минимальна: по кейсу оценивается
работоспособность, а не красота.

## Маршрут пользователя

```text
Вход/регистрация
      │  (сессия восстанавливается сама через /api/auth/me)
      ▼
Чат ──────────────────────────────────────────────────────────┐
 │  стартовый экран: 6 подсказок типовых задач                 │
 │  ▼                                                          │
 │ сообщение → ожидание → ответ + свёрнутые источники          │
 │    ├─ уточнение (clarify) — не ошибка                       │
 │    ├─ вне темы (out_of_scope) — не ошибка                   │
 │    ├─ не хватает данных — список недостающего               │
 │    └─ техническая ошибка 503/сеть — отдельный вид + Повторить│
 │  ▼                                                          │
 │ ядро отметило offer_application → предложение заявки        │
 │    ├─ «Продолжить консультацию» → чат продолжается          │
 │    └─ «Оставить заявку» ▼                                   │
 │        форма (ФИО, телефон, компания, резюме)               │
 │        ▼ «Проверить карточку»                               │
 │        карточка + галочка согласия                          │
 │        ▼ «Подтвердить заявку»                               │
 │        заявка создана, показан номер; чат продолжается      │
 │                                                             │
 ├─ «Новый диалог» → подтверждение → чистый экран, старый в архив
 ├─ «Завершить диалог» → подтверждение → диалог только для чтения
 └─ «Оставить заявку» доступна в любой момент ─────────────────┘
      │
      ├─ История: список своих диалогов → просмотр только для чтения
      └─ Проверка (только is_staff): все диалоги и все заявки
```

Переключатель «Отладка» в шапке включает под каждым ответом время, действие ядра,
статус, число источников и предупреждения. Скрытые рассуждения модели, ключи
и системный промпт не показываются и не запрашиваются.

## Экраны

| Экран | Назначение | Ключевые элементы |
|---|---|---|
| Вход | Вход и регистрация | две вкладки, подсказка про 10 символов пароля, бейдж тестового режима |
| Чат | Основная работа | панель действий, лента, поле ввода, панель заявки |
| Стартовый экран | Пустой диалог | заголовок, пояснение, 6 подсказок |
| История | Все свои диалоги | дата МСК, статус, первая реплика, число сообщений |
| Диалог из истории | Проверка прошлой сессии | лента только для чтения, карточка заявки, если была |
| Проверка (staff) | Приёмка | вкладки «Диалоги» и «Заявки», отладка включена всегда |

## Состояния, которые обязательно различимы

1. Ожидание ответа — анимация из трёх точек, кнопка отправки заблокирована.
2. Ответ с источниками — свёрнутый блок «Источники из базы знаний: N».
3. Уточнение, вне темы, нехватка данных — подпись над ответом, обычный фон.
4. Техническая ошибка — отдельный пузырь, подпись «Техническая ошибка»,
   пояснение «это сбой сервиса, а не отсутствие информации в базе», кнопка «Повторить».
5. Сообщение сохранено без ответа — подпись под репликой пользователя.
6. Диалог закрыт — поле ввода заменено пояснением.

## Мини-набор стилей

| Параметр | Значение |
|---|---|
| Акцент | `#e30611` (красный МТС), наведение `#b80510`, мягкий фон `#fdecec` |
| Фон страницы | `#f1f2f7`, карточки `#ffffff`, вспомогательный `#f7f8fc` |
| Текст | основной `#16181d`, второстепенный `#5c6270` |
| Успех / внимание | `#1f8a53` / `#b26a00` |
| Шрифт | системный: Segoe UI, system-ui, -apple-system, Arial |
| Радиусы | 14px карточки и пузыри, 10px кнопки и поля |
| Тень | мягкая, только у карточек |

Один акцентный цвет, одна тень, два радиуса. Анимация одна — индикатор ожидания,
и она отключается при `prefers-reduced-motion`.

## Доступность

- У каждого поля есть подпись; у поля ввода сообщения подпись скрыта визуально,
  но доступна скринридеру.
- Лента сообщений помечена `aria-live="polite"`: новые ответы объявляются.
- Видимый фокус у всех интерактивных элементов, модальное окно закрывается Escape
  и сразу ставит фокус на главное действие.
- Узкий экран от 360px: одна колонка, пузыри до 88% ширины, горизонтальной
  прокрутки нет.
