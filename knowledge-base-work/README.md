# База знаний Energytool — готовая папка для проекта

Перенесите папку knowledge-base-work целиком в корень своего склонированного
AI-Consultant-Anergytool, где создана ветка Ann. Файлы приложения заменять не нужно.

Внутри:
- scripts/ — скрипт воспроизводимой подготовки;
- tests/ — восемь тестов на вымышленных данных;
- docs/ — инструкция и описание ограничений;
- data/knowledge-base.zip — исходный архив организаторов;
- data/knowledge-base/ — 19 исходных документов;
- data/kb-artifacts/ — 148 фрагментов, реестр, метаданные, отчёт проверки
  и привязка 18 demo-вопросов к источникам;
- data/evaluation/ — demo CSV и фактический прогон без модели.

Сохраните скрытый файл .gitignore: он исключает вложенную папку data/ из Git.
В ветку Ann отправляются код, тесты и документация; данные остаются локально.
Исходную базу и её копии нельзя публиковать открыто по условиям кейса.
Не добавляйте data/ принудительно через git add -f. Игнорирование не удаляет
файлы, уже добавленные в Git ранее. В этом пакете нет истории или коммитов Git.

База уже подготовлена. Для проверки, находясь именно внутри knowledge-base-work:

```sh
python3 -m unittest discover -s tests -p 'test_prepare_knowledge_base.py' -v
```

Повторная подготовка при необходимости:

```sh
python3 scripts/prepare_knowledge_base.py --archive data/knowledge-base.zip
```

Нужен Python 3.10+; установка внешних пакетов не требуется. Для новой версии
архива задайте новые --sources и --artifacts, чтобы не затирать существующий корпус.

Консультант и модель автоматически к папке не подключаются. Данёк сможет использовать
подготовленные фрагменты в общем ядре. Для существующего CSV-baseline каталог данных —
knowledge-base-work/data/knowledge-base, а путь к вопросам задаётся отдельно.
Не индексируйте весь data/: там есть метаданные и примеры ответов.

Два структурных замечания источников записаны в data/kb-artifacts/manifest.json.
Целостность данных и формат CSV проверены; качество ответов модели пока не оценивалось.
Ссылки на ветку Аня в docs/ относятся к исходной облачной подготовке. Ваша ветка — Ann.
