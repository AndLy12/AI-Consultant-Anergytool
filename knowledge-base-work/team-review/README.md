# Командная разметка для проверки ядра

Здесь опубликованы 40 фактов и 30 сценариев из подготовленного командного набора.
`product_facts.csv` содержит точные цитаты исходных документов, условия,
ограничения, пути источников и номера строк. `cases.jsonl` содержит вопросы,
историю, ожидаемые действия, ссылки на факты и недопустимые утверждения.

Это материалы оценки, а не продуктовая база для индексации. Не добавляйте
вопросы и ожидаемые ответы в контекст консультанта как продуктовые сведения.
Корпус из 19 исходников по-прежнему хранится отдельно в игнорируемой `data/`.

Публикация этой папки — отдельное решение команды. Файл фактов содержит
цитаты материалов организаторов; расположение в коллективном репозитории
не делает публичный доступ закрытым и не меняет условий использования кейса.

## Проверка

Из папки `knowledge-base-work`, имея исходный корпус локально:

```sh
python3 scripts/review_knowledge_base.py \
  --review team-review \
  --output data/review/team-validation.json
```

Для проверки поиска добавьте `--core-root` с путём к проверяемому проекту
и `--core-revision` с полным SHA. Скрипт не вызывает модель.

Разметка основана на исходном архиве SHA256
`d5f1bbba0094d1eb7e4918bd7a1d37c621ae5cd498010ca2cba041ddddafd66a`.
Действия и качество настоящих ответов модели ещё требуют приёмки.
Сценарий с `context_fixture` выполняется отдельно в проверочной копии контекста.
