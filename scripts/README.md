# Скрипты

`build_core_submission.py` собирает плоский кандидат ZIP из ядра Данька,
без закрытых данных и веб-зависимостей. `check_core_knowledge.py` проверяет
загрузку базы, разбор вопросов и поиск без модели. Формат и ограничения:
[инструкция ядра](../core/README.md).

`role3_acceptance.py` готовит очередь содержательной проверки и журналирует
реальные вызовы только с `--execute`. Закрытые наборы читаются из
`knowledge-base-work/data/review/`, там же сохраняются доказательства.
Без API фиксируется блокер; ответы не заменяются demo или эталонами.
Порядок проверки и ручной оценки: [ROLE3_ACCEPTANCE.md](../docs/ROLE3_ACCEPTANCE.md).

Тесты журнала не требуют API или закрытых материалов, из корня проекта:

```bash
python -m unittest discover -s tests -p test_role3_acceptance.py -v
```
